# Launch A Hotdog Not Hotdog Web App!

Part of this system check entails making sure we have all the necessary libraries installed. You can see which libraries are needed by checking requirements.txt. This text file also comes in handy as we can now directly install anything we're missing.

### 1. In the terminal window, type in the following command:
  ```pip3 install -r requirements.txt```  

<img width="1304" height="495" alt="image" src="https://github.com/user-attachments/assets/be441c20-a97c-49cd-82c7-f9c6c075b24d" />
  
> It may take about a minute for the libraries to install.
---
### 2. To launch the app, enter the following command into the terminal:
   ```python3 -m flask run```    
   
This will run the `app.py` file with Python. If you see the following, then your app has run successfully.

<img width="1315" height="168" alt="image" src="https://github.com/user-attachments/assets/157aa354-45e0-46af-9c21-f4b83e1f4531" />

---

### 3. Now that your app is up and running, we can see how it looks by navigating to the [Skills Network](https://skills.network/) Toolbox:  

<img width="1649" height="855" alt="image" src="https://github.com/user-attachments/assets/35fcd69a-c813-447d-91e3-16642285bc54" />  

Select `Other > Launch Application` and type in the *port number*, which you can see in terminal. In this case, it's `5000`.

>You can choose to launch the application either through `Your Application` or the pop-out button next to it. The former will launch the application in the same tab in a smaller window and the latter will open a new tab with the page. You can choose whichever you feel more comfortable with or even try both!  

<img width="2528" height="1512" alt="image" src="https://github.com/user-attachments/assets/53fa97b1-d6e9-4fe1-a068-070f4c993efe" />
